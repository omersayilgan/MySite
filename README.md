# omersayilgan.com

Personal site of Ömer Sayılgan, Control Systems & GNC Engineer. It is a static site with no build step, served by GitHub Pages at [omersayilgan.com](https://omersayilgan.com).

| File | Purpose |
| --- | --- |
| `index.html` | The whole site (single page) |
| `styles.css` | Styles, with light and dark mode |
| `cv.pdf`, `transcript.pdf`, `transcript-metu.pdf`, `reference-letter-phlair.pdf` | Downloadable documents |
| `cv.html`, `skills_hobbies.html` | Redirects from the old page URLs |
| `404.html` | GitHub Pages not-found page |

To preview locally, run `python3 -m http.server` in this folder and open http://localhost:8000.
